# أداة استرجاع الملفات المحذوفة — File Recovery Tool

هذا المستودع مخصّص لنشر إصدارات البرنامج لنظام ويندوز. كل إصدار موجود في صفحة
[Releases](https://github.com/ssmm6000/FileRecovery-Releases/releases) ومعه ملف التثبيت.

- **التثبيت:** نزّل ملف `recovery-gui_<الإصدار>_x64-setup.exe` من آخر إصدار وشغّله.
- **التحديث:** من داخل البرنامج اضغط زر **"تحديث البرنامج"** — يتحقق من آخر إصدار هنا، وينزّل
  المثبّت ويتحقق من سلامته (الحجم وبصمة SHA-256) قبل تشغيله.

---

This repository publishes the Windows releases of the program. Each release on the
[Releases](https://github.com/ssmm6000/FileRecovery-Releases/releases) page carries its installer.

- **Install:** download `recovery-gui_<version>_x64-setup.exe` from the latest release and run it.
- **Update:** inside the app, press **"Update App"** — it checks the latest release here, downloads the
  installer and verifies it (size and SHA-256 digest) before running it.
